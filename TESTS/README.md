# TESTS

## Purpose

The TESTS directory contains automated tests for the engineering utilities within the TOOLS directory.

As repository automation grows, every significant validation tool should have corresponding tests to verify correct behavior and prevent regressions.

The long-term goal is to support reliable, repeatable repository validation through automated testing.
