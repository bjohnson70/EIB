# TOOLS

## Purpose

The TOOLS directory contains engineering utilities that support the development and maintenance of the Executive Intelligence Briefing (EIB) repository.

These tools validate repository quality, automate repetitive engineering tasks, and provide health reporting for the repository.

Typical utilities include:

- Metadata validation
- Document ID validation
- Link validation
- Repository health reporting
- Repository structure validation
- Document catalog validation

These tools support the repository itself rather than the Executive Intelligence Platform application.
