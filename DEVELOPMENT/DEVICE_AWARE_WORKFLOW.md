# Device-Aware Development Workflow

## Purpose

This document defines how EIB development work should adapt to the device currently being used by the project owner.

The objective is to reduce friction by selecting the development workflow that best matches the available device, interface, and repository permissions.

The user should not need to repeatedly explain which workflow applies.

---

# Guiding Principle

> Use the most capable workflow available on the current device without creating unnecessary manual effort.

Device context should influence **how work is performed**, not the technical standards or quality of the resulting repository changes.
